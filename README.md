
🚀 Java Simple Inheritance Example

This project demonstrates the fundamental concept of **Simple Inheritance** in Object-Oriented Programming (OOP) using Java.

-----

### 💻 How to Run the Code

1.  **Clone the Repository:**

    ```bash
    git clone [Your Repository URL Here]
    ```

2.  **Compile the Classes:**
    Navigate to the directory containing the Java files and compile them:

    ```bash
    javac A.java B.java Exercise01.java
    ```

3.  **Execute the Program:**
    Run the main class (`Exercise01`):

    ```bash
    java Exercise01
    ```

### Expected Output

The program is expected to print the message defined in the parent class, regardless of whether the `hello()` method is called on the `A` object or the inherited `B` object.

```
Hello from A!
Hello from A!
```

*(Note: Assuming you initialized `message` in class A to "Hello from A\!")*
